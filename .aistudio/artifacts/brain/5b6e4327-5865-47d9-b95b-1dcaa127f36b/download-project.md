### 💻 How to Open and Run in Visual Studio Code (Windows):

1. **Extract the ZIP**:
   - Locate `ghee-panjiri-website.zip` in your Windows `Downloads` folder.
   - Right-click the file and select **"Extract All..."**, then click **Extract**.

2. **Open in VS Code**:
   - Open Visual Studio Code.
   - Click **File** > **Open Folder...** (or press `Ctrl + K, Ctrl + O`).
   - Select the extracted project folder.

3. **Install Dependencies**:
   - Open the integrated terminal in VS Code (`Ctrl + ~` or `Terminal` > `New Terminal`).
   - Run the following command:
     ```bash
     npm install
     ```

4. **Start the Development Server**:
   - In the terminal, run:
     ```bash
     npm run dev
     ```
   - Open your browser and navigate to: **`http://localhost:3000`**
